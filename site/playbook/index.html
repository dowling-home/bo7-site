How to use this playbook

Two rules, and one setup step

Each step has what to do, who does it, and the prompts to paste into Claude.

  1. Every prompt starts from the Bo7 brand position. Paste it in, or keep it in a Claude Project, so every output sounds like Bo7 and not a generic gym.
  2. A person approves anything before it is sent. Claude drafts; Ryan and the coaches decide and send.

Setup: the prompts are written for Claude Code in the Claude desktop app, with the Claude in Chrome extension connected. That lets Claude work in your own browser: clicking through settings pages like DNS, Google profiles, Google Forms and ad accounts while you watch.

  • Connect Google Drive to Claude with the Bo7 Google account (Settings, Connectors). Claude can then read and update the leads sheet, survey results and other Bo7 files directly.
  • You sign in to every site yourself. Claude never types a password.
  • Claude shows you what it is about to change and waits for your OK before it saves, sends or deletes anything.
  • Keep everything in one Bo7 folder that Claude Code works in (the bo7-site project is a good home): the brand position, the scorecard and any exports. Then a prompt can say "using the project files" instead of pasting everything in.
