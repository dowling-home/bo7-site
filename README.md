# Bo7 website rebuild

Static rebuild of [bo7.ie](https://www.bo7.ie) (semi-private personal training, Blackrock and Killiney).

- `site/` — the website. No build step; GitHub Pages serves this folder.
- `source/` — content pulled from the current site (copy, inventory). Originals and videos are kept out of git.
- `AUDIT.md` — what was wrong with the old site and the plan.
- `HANDOVER-NOTES.md` — differences versus the old site and things to fix on their side.
